# Arquitectura

Documentacion de arquitectura del proyecto UTM Dev Labs.

## Contenido

Esta carpeta contendra:

- **ADRs (Architecture Decision Records):** Registro de decisiones tecnicas importantes.
- **Diagramas:** Diagramas de componentes, secuencia, despliegue, etc.
- **Stack tecnologico:** Descripcion del stack elegido y justificacion.
- **Infraestructura:** Configuracion de ambientes (dev, produccion).

## Formato de ADR

Cada decision de arquitectura se documenta con este formato:

```
# ADR-NNN: Titulo

## Estado
Propuesto | Aceptado | Deprecado | Sustituido

## Contexto
Que problema estamos resolviendo.

## Decision
Que decidimos hacer.

## Consecuencias
Que implica esta decision (positivo y negativo).
```
